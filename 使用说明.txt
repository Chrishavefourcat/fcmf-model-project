模型评级系统 · SQLite 源码网页版本

1. Windows 10 / 11 在项目文件夹双击 start.bat，或在终端执行 powershell -File .\start.ps1。需要有常用浏览器。
   脚本检查已有可用 Python 3.10+；没有时自动从 python.org 下载完整 Python 3.14.10，校验后放到当前用户的 %LOCALAPPDATA%\ModelRatingSystem\python\ 缓存目录，无需管理员安装。
   首次自动准备环境需要联网访问 python.org 和 Python 包安装源；网络失败时按提示处理后重新双击。已在 Windows x64 验证，x86 / ARM64 有下载配置但尚未实机验证。
   Linux 在项目目录执行 sh start.sh；先交由 agent 准备环境时请阅读“启动依赖与Agent操作清单.md”的 Linux 专节。
   启动脚本首次创建 .venv 虚拟环境并安装 requirements.txt 依赖，需要网络或配置好的离线安装源。以后运行复用环境，依赖清单变化或环境不完整时才重新安装。
2. 服务启动后自动用默认浏览器打开评分页面。默认地址端口为 8765，初始显示“未选择数据源”，由客户进入页面后选择自己的数据库；没有 models 文件夹也能启动。手动重开页面时，使用终端打印的完整地址（包括会话参数）。
3. 在第一步，点击“模型选择”右侧的“数据源选择”，输入本机模型文件夹或单个 .db 文件路径；也可点输入框右侧“浏览…”下拉中的“选择文件夹”或“选择 DB 文件”，在 Windows 系统对话框中选取，回填路径后点“使用此数据源”确认加载。
   取消浏览或浏览失败时，保留原输入和原数据源。浏览仅选择本机路径，不上传、不复制文件，业务直接使用原文件；轻量系统对话框不增加 Qt 或打包依赖。
4. 从下拉框选择模型，点击“样本选择”输入框即可浏览公司候选列表，也可输入名称、统一代码或债券代码搜索；点击候选公司加入样本，再按步骤完成数据录入和评级。
   下拉列表顶部可全选当前模型全部公司；输入关键词后可全选全部匹配公司，已选公司不会重复添加。
   右侧可搜索已选样本，逐行删除或勾选后批量删除；表头复选框仅全选当前显示的样本。删除仅移除本次评级样本，不删除数据库中的公司。
5. Excel 导出通过浏览器下载，保存目录及是否弹出另存为窗口由浏览器设置决定；导入时在页面选择需要的 Excel 文件。
6. 使用完成后，在启动程序的终端按 Ctrl+C 停止服务。关闭浏览器标签页不会停止 Python 服务；关闭或刷新页面前，请导出要保留的页面数据。
7. 点击“下一步”逐步解锁后续页签；未解锁的页签不可点击。已走到的步骤可以自由返回，切换模型、数据源或删除全部样本后重新从第一步开始。
   界面为紧凑自适应布局，主体随浏览器宽度展开；表格在桌面端利用剩余高度，长数据在表内滚动。窄窗口可横向滚动步骤和表格，当前步骤自动显示；较大缩放和小窗口支持整页滚动。长列名、公司名称及异常提示可悬停查看完整内容。
   第一步的“原定级”读取对应 company_id、field_id 为 original_grade 的 field_value，优先所选数据日期，无该日期记录时读取未标日期的记录；没有数据则留空。
   第二步按模型 indicator.expression 中直接引用的 field_id 提取源数据，按出现顺序去重；无表达式的指标使用绑定字段。共享源数据仅显示一次，首次引用时排在对应指标之前。
   源数据读取对应公司、字段、所选日期的 field_value；普通字段无该日期记录时读取未标日期记录，排查字段严格匹配所选日期。
   “展示指标 / 隐藏指标”控制蓝色指标计算列，默认隐藏。源数据列头只显示名称，不展示下方的 field_id。鼠标放在指标表头或数据格上可查看表达式，字段标识按当前模型 field 表的 label 显示为对应中文名称；函数、数字和引号里的常量保留，未配置名称的标识保持原样。该转换仅用于展示，实际计算仍使用原始表达式。指标值按模型公式和当前页面源数据计算，展示乘权重前的计算值。
   所有源数据单元格均可直接输入数字或文本，输入停顿约 250 毫秒后自动重算该主体的指标值及评级；开启“展示指标”可实时看到蓝色计算列更新。计算期间保持输入焦点及录入精度，未编辑的值不变，空白与零分别保留；离开输入后再按新值排序筛选。相关指标的计算值变化后恢复公式评分，其他项及其他主体的手动修改保留。计算中或请求失败时暂停下一步及导出，失败保留输入，重新编辑可重试。仅当前页面生效，不写入数据库。
   点击源数据列头的中文名称，可按列修改：弹窗列出全部已选公司，主体名称下方不显示公司 ID，分别填写这一个字段的值。保存后仅更新有改动的公司并重新计算指标和评级；未改动的值保留原始精度，清空保持空白，零值正常保留。取消不保存，计算失败可在弹窗重试；行内“排查”可按公司修改多个字段，中文名称下方不再展示字段标识。所有修改仅在当前页面生效，并同步到导出，不写入数据库。
   “按列修改”弹窗支持按主体名称或字段值升序、降序、恢复原顺序、搜索勾选、全选、反选、重复项、唯一项及清除此列筛选，空白与零分开显示；显示“可见数 / 总数 家公司”，并可清除全部排序和筛选。弹窗条件与主表独立，重新打开时恢复全部公司和原顺序。排序和筛选不会丢失输入，保存包含被筛选隐藏的全部已修改公司；取消放弃本次修改，失败保留输入和筛选条件供重试。输入期间保留焦点，离开输入区域后再按新值排序筛选。
   主体名称、源数据和蓝色指标列的排序筛选图标位于标题右侧、垂直居中，不再单独占据表头底部一行；标题与编辑图标分开留位，长标题最多换两行。展开后可升序、降序、恢复顺序，搜索并勾选值，支持全选、反选、重复项、唯一项以及清除此列筛选。空白与 0 分开筛选，多列条件可叠加，选项旁显示公司计数；工具栏显示当前可见数量，并可“清除排序和筛选”。搜索可用空格分隔多个关键词，匹配任意关键词后点“确定”生效，取消或点外部不保存。
   第三步的主体名称、初评得分、初评等级，以及每个指标的“指标值、赋分、得分”也支持排序筛选；图标位于文字右侧并垂直居中，序号与主体名称居中对齐，不再为箭头单独留底部一行。第四步为主体名称和各排查项的“指标值、得分”，第五步各结果列也使用同样的图标和弹框。第二至第五步分别保留条件，切换步骤互不影响。编辑值或得分后使用最新数据，输入期间保持焦点，离开表格后重新排序筛选。
   排序筛选仅作用于所在步骤显示，样本、整列编辑范围、Excel 导出及后续评级仍使用全部已选公司及原样本顺序；切换模型、数据源、日期或第二步重置数据库数据时清除各步条件，第四步重置排查数据时清除该步条件。
   “展示指标 / 隐藏指标”旁仅以“当前可见数 / 总数 家公司”显示公司数量，不追加已筛选列数或升降序文案，不展示公式无法计算的汇总提示。源数据计算完成后不显示成功提示，计算中和请求失败时仍显示对应状态。
   第二步导出始终包含全部源数据列及每个指标的“指标值”，与页面显示值一致（包括四位小数的显示精度），不包含“赋分”和“得分”，指标列使用蓝色背景。指标表头批注显示当前生效的计算表达式。“指标信息”工作表列出指标名称、权重、表达式和关联字段。
   第二步导入按主体 ID 和字段 ID 回填当前已选样本的源数据，包含零值和空白。每次成功导入后，无论源数据是否变化，均按当前页面生效的公式重新计算指标值，并更新后续得分、等级及导出结果。Excel 中的指标值列仅用于展示，不覆盖重新计算的结果；旧模板的得分列不作为输入。导入值和计算结果仅保留在当前页面，不写入数据库。第五步排查得分以第四步页面为准。
   刷新、关闭页面、切换模型/数据源/日期或第二步重置会清除导入值。手动修改源数据或指标表达式后重新计算指标值，单独修改权重时重新计算对应得分。第四步修改、导入或重置排查数据时，重新计算排查指标。
   第三步“指标值”可直接编辑，按关联 field_id 保存到当前页面并重新计算赋分、得分和等级；同一字段被多个指标引用时同步更新，不影响其他主体，导出也使用页面修改值。
   第三步表头权重可直接修改数值，百分号为固定单位，例如输入 10 表示 10%，对应评分规则配置中的 0.1。只接受非负数，非法输入不生效，离开时恢复最后有效值；未编辑的权重保持原精度。修改对当前模型全部主体立即生效，保留手动赋分，按新权重更新得分、等级、后续编辑和导出；权重 0 继续沿用原模型直接记分的规则。源数据计算期间暂停权重编辑，仅当前页面生效，不写数据库。
   第三步还可点击指标最上方的中文名称，弹窗按公司同时编辑“指标值、赋分、得分”；指标值变化时预览公式结果，赋分与得分按权重联动，并使用当前评分上下限。第四步点击排查项最上方名称，可同时编辑“指标值、得分”，指标值变化后预览公式结果，手动得分优先，之后再改指标值会恢复公式计算。
   两种弹窗打开时均列出全部已选公司，主体名称下方不显示公司 ID；各列均支持排序、搜索勾选、全选、反选、重复项、唯一项及清除条件，显示“可见数 / 总数 家公司”。弹窗条件与主表独立，重新打开时恢复原顺序；排序筛选保留未保存输入，保存包含被隐藏的全部已修改公司。预览仅在弹窗中显示，确认后统一保存并更新评级、排序筛选和导出；取消放弃本次修改，失败保留输入和条件供重试。未修改的数据保留原精度，空白与零分别保留，修改仅在当前页面生效。
   第三、四步指标值缺失时显示空白，不填充默认值或 0.0000，实际零值仍显示 0.0000；清空后保持空白。计算仍沿用现有公式和默认值规则，仅当前页面生效，不写数据库。
   第三步可点击“评分规则配置”，按“编辑”修改指标权重和取值公式，其他内容只读；操作列“取消编辑”下面的“确定”会立即保存当前行并重新评分，取消编辑则恢复上次确认的值。底部“确定”可提交其他修改并关闭窗口。
   评分规则仅保存于当前页面，不写入数据库；第二步导出会包含当前规则和对应指标结果。刷新、关闭页面、切换模型/数据源或点击第二步“重置为数据库数据”后恢复数据库规则。
   第三步“等级规则配置”位于“评分规则配置”右侧，仅展示 grade 表 status 为“打分映射”且 inclusive 为 1 的记录，空 threshold 视为 -99999，末行右边界默认为 99999。
   可以编辑左、右边界，相邻边界自动联动；越界、交叉、空值和零长度区间会报错。点击行内“确定”或底部“确定”后应用规则，未确认的编辑可取消或关闭丢弃。
   删除中间或末尾行时由前一行承接该区间；删除首行时下一行继承原左边界，至少保留一行。区间左闭右开，末行包含右端点。
   等级规则只在当前页面生效，不写数据库；刷新、切换模型/数据源或第二步重置后恢复原规则。未匹配到等级时显示红色“等级匹配异常”，重新匹配成功后恢复正常。
   无页面等级修改时，重新评分、打开等级规则配置或回到浏览器标签页会重新读取数据库等级规则。弹窗展示实际 .db 文件路径；在外部数据库软件修改后需保存/提交事务。已保存的页面等级修改优先生效，可点击“读取数据库最新规则”清除页面等级修改并恢复数据库最新值，其他页面数据不受影响。
   未编辑规则时同样按配置窗口中的完整区间判断；低于首行左边界或高于末行右边界时显示异常，首次打开、刷新、重置及后台评分接口均采用此规则。
8. 第四步“批量排查”显示序号、主体名称及各排查项的“指标值、得分”两列。排查项来自 field 表 field_type 为“排查项”的记录，名称取 label。
   指标值读取对应 field_id 的值，支持数字和文本。得分根据 indicator.field_id 关联的 expression 计算，直接采用公式结果，不乘权重、不套用指标上下限或舍入位数；无关联公式时采用数值指标值。多个指标绑定同一字段时按指标 ID 顺序使用第一个指标。
   两列均可修改：修改指标值实时计算得分；手动改分后优先采用手动值，再改同一项指标值时恢复该项公式计算，其他项的手动得分保留。公式无法计算时可修正指标值、表达式或手动填写得分。
   指标值严格按 company_id、field_id、period_end 匹配，不读取未标日期或其他日期记录。页面录入或导入优先，所选日期无值或清空时保持空白；得分计算仍沿用模型默认值规则，不把默认值填入输入框。
   指标值和手动得分按公司、字段、日期分别保存；切换日期不会串值，切回可继续使用本次修改。刷新、关闭页面、切换模型或数据源后恢复数据库数据。
   “重置为初始数据”重新读取数据库，清除当前日期已选主体在第二或第四步录入、导入的排查字段值及手动得分。其他源数据与页面评分规则继续生效，数据库文件不会被修改。
   导出使用第四步页面快照，每个排查大项下只有“指标值、得分”，主体范围和顺序、当前值及手动得分与页面一致。所有数据格均有细黑色框线，表头分层，支持自动换行及冻结行列。
   导出后修改指标值再导入会重新计算得分；修改得分则按手动值生效。隐藏元数据保留原始值、手动得分标识，原样导入保留自动/手动状态，部分字段导入不会清除其他字段的手动得分。旧模板的“排查分”兼容作为指标值导入。
   导入按主体代码、字段标识匹配当前样本。不要修改表头、隐藏标识或日期，含 Excel 公式时先粘贴为值。导入仅改变当前页面，不写回数据库；关闭前请导出需要保留的数据。
9. 第五步“排查得分”汇总第四步各项“得分”，包含公式结果和手动得分；原始文本指标值先按公式转为得分，不直接参与汇总。
   汇总后按 ROUND_UP 保留并固定显示 4 位小数（远离 0 进位），不是逐项进位。例如 1.23451 → 1.2346，-1.23451 → -1.2346，0.1 + 0.2 → 0.3000。
   最终得分 = 指标得分 + 排查得分，最终等级随之重新匹配；得分计算中或存在异常时，需先完成计算或修正异常，再进入最终定级或导出。
   点击“数据导出”生成评级样本、数据录入、初步评级、评级模型、等级策略、批量排查、最终定级共 7 个工作表，默认打开最终定级。仅包含当前页面样本，保留源数据、手动评分、排查指标值与得分、临时评分规则及等级区间，不重新计算或写入数据库。
   排查合计显示 4 位小数，数据区域有边框，文件名添加时间戳。最终定级的“在库定级”使用第一步原定级；历史定级、调整方向、入库状态无对应页面数据，暂留空。

页面与所有 Excel 导出的业务数值统一按 ROUND_UP 保留并显示四位小数，整数和零补足四位；例如 1.23451 显示为 1.2346，-1.23451 显示为 -1.2346。源数据、指标值、赋分、得分、权重、等级边界及合计均适用；主体代码、债券代码、日期、年份、序号以及公式和说明中的文字保留原格式。此规则仅作用于显示和报表，实际计算与等级匹配继续使用原值，数据库不变。导出时必要的原始精度保存在数值单元格批注中，未修改数值直接导回时按原值计算；修改后按新录入值计算。
所有 Excel 导出统一采用参考表样的宋体 11 号字、灰底黑字表头、细黑色边框和白底数据区，第二步及最终报告中的数据录入表保留蓝色指标列以区分源数据。列宽、行高按内容适配，长文本自动换行，序号按整数显示。
所有 Excel 导出文件名均追加导出时的年月日时分秒时间戳（YYYYMMDD_HHMMSS），例如 模型数据录入_2025-12-31_20261021_143025.xlsx。重名文件的处理由浏览器决定。

模型文件要求
- 数据源为文件夹时读取当前层级的全部 .db 文件，扩展名不区分大小写；为单个 .db 时只加载该文件，即使同目录另有其他 .db。
- 文件名没有 _model 后缀限制，例如 河南城投2026.db、模型A.db 均可。
- 每个文件对应一个模型，需包含 company、field、field_value、indicator、grade、model 六张表，结构与项目原始 SQLite 模型一致。
- 模型选择框仅显示实际 .db 文件名（含扩展名），按文件名排序，列表扫描不读取 model 表的 model_name；鼠标悬停显示完整路径。右上角“数据库”显示当前实际文件名，悬停可核对完整路径；切换时按文件读取对应数据。
- 文件夹数据源中新增模型文件后刷新页面即可识别；单文件数据源始终只加载指定文件。
- 确认切换数据源后，下拉框清空旧模型列表并只显示新数据源的模型；已选样本、录入值、评分规则和评分结果同时清空，较慢返回的旧列表不会覆盖新数据源。取消选择或加载失败时保留原数据源。
- 切换模型也会清空当前页面的样本、录入值和评分结果。

运行环境与启动参数
- Linux 在项目目录运行 sh start.sh；仅准备环境运行 sh start.sh --check-only；不打开浏览器运行 sh start.sh --no-browser --port 0。参数使用 --models、--port、--no-browser。
- Linux 需要 Python 3.10+、pip、venv、sqlite3 和浏览器；“浏览”选择窗口目前仅适用于 Windows，Linux 请直接输入模型路径或通过 --models 指定。macOS 尚未实测。
- 给接收方 agent 的安装和启动清单见同目录“启动依赖与Agent操作清单.md”。交付默认只携带代码、页面资源和说明，不附带示例模型，Python 与依赖在目标电脑安装。
- 固定依赖为 SQLAlchemy==2.0.57、openpyxl==3.1.5，兼容 Python 3.10。无需 Node.js、npm、Java 或额外数据库服务。
- 仅准备并校验环境：powershell -File .\start.ps1 -CheckOnly。首次指定 Python：powershell -File .\start.ps1 -Python "C:\实际Python目录\python.exe" -CheckOnly。
- 禁止自动下载 Python：powershell -File .\start.ps1 -NoAutoPython -CheckOnly；仍可复用已有 Python 缓存，缺少解释器时提示手动准备。
- Python 3.10+，以及 Chrome、Edge、Firefox 等常用浏览器；Windows 可直接使用启动脚本。
- 仅安装 requirements.txt 中的 SQLAlchemy 和 openpyxl。SQLite 随 Python 提供，无需另装 MySQL、SQLite 服务或数据库账号。
- 模型文件和所在文件夹需具备读写权限。项目 models 文件夹仅是可选示例，不自动加载；不携带或删除该目录不会影响打开应用，评分前再选择有效数据源。
- 已安装依赖的环境可以直接运行 python app.py。手动准备环境的方法见 README.md。
- 指定数据源和端口：python app.py --models "E:\模型文件" --port 8766；--models 也可填写单个 .db 文件的完整路径。
- 暂不自动打开浏览器：python app.py --no-browser，再手动打开终端打印的完整地址。
- 启动脚本同样支持：powershell -File .\start.ps1 -Models "E:\模型文件" -Port 8766 -NoBrowser，-Models 也可指定单个 .db 文件。
- 可用 MODEL_DIRECTORY、PORT 环境变量设置默认数据源路径和端口，命令行参数优先。默认端口被占用时，先停止已有服务或换一个端口；--port 0 可自动选择可用端口。
- 项目使用源码运行，不生成 EXE 或安装包。可将整理好的交付源码目录压缩发送；接收方根据启动清单准备环境，虚拟环境在目标电脑重新创建。

依赖安装完成后，日常评级和导入导出不需要联网。本地服务仅监听 127.0.0.1，供当前电脑使用。评分预览和 Excel 导入仅改变页面数据；数据维护功能会写入所选模型文件。
